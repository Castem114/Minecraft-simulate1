# 方块世界 · 我的世界复刻（浏览器体素沙盒）

一个用 Three.js 从零实现的《我的世界》核心玩法复刻。纯前端、零依赖、
**完全离线可运行**（three.js 已内嵌在 `vendor/`，无需联网）。

## 运行方式

任选其一：

1. **本地服务器**（推荐，也支持离线）：双击打开 `index.html` 以外的另一种方式——
   ```bash
   cd minecraft-clone
   python3 -m http.server 8377
   # 浏览器打开 http://127.0.0.1:8377
   ```
2. 直接双击 `index.html`（Chrome/Edge 对 `file://` 下 ES 模块有限制，仍推荐方式 1）。

## 操作

| 按键 | 功能 |
| --- | --- |
| 点击画面 | 锁定鼠标开始游戏 |
| `WASD` | 移动 |
| `空格` | 跳跃（双击空格切换飞行） |
| `Shift` | 潜行（飞行时下降） |
| `Ctrl` | 疾跑 |
| 鼠标左键 | 破坏方块（长按连续） |
| 鼠标右键 | 放置方块 |
| 鼠标中键 | 吸取瞄准的方块 |
| `1-9` / 滚轮 | 选择快捷栏方块 |
| `F` | 切换飞行模式 |
| `G` | 暂停 / 继续昼夜循环 |
| `P` | 清除存档并重建世界 |
| `Esc` | 暂停（呼出菜单） |

## 特性

- **程序化地形**：多倍频值噪声生成丘陵、海滩、雪峰、洞穴，确定性种子（每次进入世界相同）
- **分块渲染**：10×10 块（160×160×48），隐藏面剔除、逐面法线烘焙明暗、图集 UV 防出血
- **程序化纹理**：Canvas 逐像素生成 16 格纹理图集（草/土/石/沙/木/叶/砖/玻璃等 13 种方块）
- **物理系统**：轴分离 AABB 碰撞、重力、跳跃、疾跑、潜行、飞行
- **方块交互**：体素 DDA 射线拾取、破坏/放置/吸取、白色高亮线框 + 绿色放置幽灵预览
- **昼夜循环**：太阳/月亮/星空/云层/雾气/天空渐变、动态光照
- **粒子与音效**：破坏碎块粒子、WebAudio 程序化音效
- **本地存档**：方块改动、玩家位置/飞行状态持久化到 localStorage（每 3 秒节流），`P` 键重置
- **智能出生点**：自动寻找干净空地，或恢复上次存档位置

## 技术要点

- 每个区块 `16×16×48` 的 `Uint8Array` 体素数据，破坏/放置只重建受影响区块的合并网格
- 光照 = 每个面按朝向烘焙的顶点亮度 + 方向光/环境光，无需逐方块光照计算
- 射线拾取为 Amanatides & Woo 体素遍历，O(步数) 且无三角面求交

## 可调参数

`game.js` 顶部：`WORLD`（区块数）、`HEIGHT`（世界高度）、`REACH`（交互距离）、
`DAY_LEN`（昼夜时长，秒）。配置较低时可将 `WORLD` 改为 6~8。
